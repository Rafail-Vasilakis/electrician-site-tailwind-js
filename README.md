# Local Service Business Platform - Marousi, GR

A high-performance, mobile-first web application designed for local tradesmen (Electricians/Plumbers). Optimized for instant lead generation and local search visibility.

## 🚀 Key Features
- **Mobile-First UX:** Large touch targets for emergency calls.
- **Local SEO:** Integrated JSON-LD Schema for Marousi-based search ranking.
- **Performance:** Sub-1s loading times using Vite and optimized WebP assets.
- **Conversion:** WhatsApp/Viber floating widgets and SMTP-ready contact forms.

## 🛠️ Tech Stack
- **Framework:** React 18 (TypeScript)
- **Build Tool:** Vite
- **Styling:** Tailwind CSS (recommended for fast UI dev)
- **Deployment:** Vercel / Netlify

## ⚙️ Setup
1. `npm install`
2. `cp .env.example .env`
3. `npm run dev`
